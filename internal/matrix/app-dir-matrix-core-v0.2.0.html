Local CodeGraph handoff

            
This HTML deliberately does not infer calls/imports from filenames. Use CodeGraph locally for symbol/call/dependency truth, then import JSON to overlay semantic edges on the structural tree.


cd /path/to/repo
codegraph init
codegraph status --json
codegraph files . --json > codegraph-files.json
codegraph explore "entrypoints architecture call paths" --json > codegraph-explore.json
codegraph ui .

            
The importer is permissive: it scans JSON for common edge shapes such as from/to, source/target, caller/callee and file/path references.
